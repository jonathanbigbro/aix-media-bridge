# 有声制作：从内容要求到可编辑工程

仅在用户需要配音、字幕或有声剪辑时读取。本项目的 schema 2 已验证 1280×720、24fps、720 帧；这是当前适配范围，不是通用创作模板。命令与数据结构见仓库 [docs/NARRATED-VIDEO.md](../../../../docs/NARRATED-VIDEO.md)。

## 先决定观众看什么

区分操作演示、故事短片和宣传介绍。制作前把受众、叙事重点、画面风格、旁白密度和已有参考整理成简短分镜；缺少会影响视觉方向的信息时尽早询问，其他准备可继续。不要默认将“介绍工具”做成六页大字说明卡，也不要为填满时长强行新增 AIX 生成任务。真实界面、生成故事画面与后期说明文字各自承担明确作用。

先用代表性的画面/版式检查信息密度、屏幕可读性和节奏，再进行完整本地渲染；是否需要用户确认，沿用会话已有约定。用户认可工作流并不等于认可剪辑审美。技术验收结果与视觉意见分别保留。

## 独立配音和字幕

1. 优先在隔离环境安装 `audio/requirements.txt` 并查询 edge-tts 当前普通话声音。先合成和播放短样音，检查产品名、语速和停顿。本次验证使用 Xiaoxiao 普通话声音，正常语速；不把它写成唯一可用声音。外部 TTS 只接收用户授权的旁白文本。
2. `audio/narrate.py` 读取独立文案，保存原 MP3、词时间戳和 48 kHz PCM16 单声道 WAV。根据实际声音长度安排画面，过长时修改文案或分配时长，不能截尾或明显加速硬塞。改配音使用新的音频修订目录，不触碰 AIX 任务。
3. `audio/captions.py` 从 `narration.json` 的真实 WordBoundary 产生 SRT 和帧级 `timeline-cues.json`；保留 `text` 与 `spokenText` 的区别，例如屏幕写 AIX，发音可写 A I X。字幕使用原显示文案，不能照搬语音识别的错字。无时间证据时停止自动对齐。
4. 每条字幕最多两行，按实际画面检查手机可读性、对比度、安全边距与切点。当前配套脚本按一句旁白生成一条字幕；长句应在文案阶段合理分段。SRT 只是配套交付；Resolve 中还必须存在真正的可编辑文字。

edge-tts 不可用时检查本机已安装中文语音或已有官方配置。新增付费服务先说明配置与费用要求。无法直接接收音频输入时，说明主观听感检查的限制，结合实际播放、解码、波形和本地转写辅助核验；转写幻觉不能当作影片里存在的声音。

## Resolve 的实际联动

先读取本机官方脚本说明，并运行 `npm run edit -- doctor`。创建独立工程，使用 `plan → build → run`；V1 放画面，V2 放透明载体上的 Fusion Text+ 标题/中文字幕，A1 放旁白。当前字幕实现是 Text+，不是原生字幕轨。不要仅把 SRT 放在输出目录就声称字幕已上轨。

- 单声道 WAV 放在显式创建的 mono 音轨。Resolve 默认 stereo 轨可能把它只路由到左声道。先新增 mono，再移除确认为空的默认轨；不能删除或替换其他工程的有内容音轨。音量在真实时间线/检查器内调整，最终文件应双声道居中且不削波，不能照抄一次项目的增益值。
- Fusion 修改使用 StartUndo/Lock、写入 Text+/Merge、Unlock/EndUndo，并激活实际合成、保存工程。保存返回成功可能早于合成提交；必须等待 `COMPB_Modified` 为 false，再验证文本和连线。否则导出可能缺字幕或遮罩。
- 有声 schema 2 使用 `audio:true` 和 `ExportAudio:True`，Resolve 原生 H.264/AAC 导出。schema 1 的 `audio:false`、`ExportAudio:False` 和零音轨验收继续只用于无声任务。
- 修改内容时用新的配置文件、递增 `revision` 和上一版 `configDigest`，执行 `revise`。保留旧 MP4、DRP、配置和渲染记录；本地重剪不授权重复上传、生成或下载。中断时核对原工程并 resume。

## 最终文件和工程验收

完整解码实际 MP4，检查视频帧数/尺寸/fps、可解码音轨、每声道非静音与平衡、削波、首尾活动音频及与原 WAV 的时序。波形一致不能证明声音自然；单独记录听感范围。AAC 填充可能让音轨或播放器略长，视频轨、音轨、容器各自记时，不为凑容器整秒切掉旁白。

播放导出文件并检查首尾、全部切点和字幕出现/消失附近的实际帧。真实界面先裁除或遮罩账号、余额、私人路径/历史项目，再入时间线；导出后重查遮罩像素和关键帧，不能只查节点存在。字幕、品牌、模型与功能表述必须和真实画面一致。

保存关闭并重开自有工程，验证媒体哈希/链接、视频长度、音轨和 Text+ 文字。DRP、配套 media、旁白 WAV、文案和 SRT 为私人工作交付，包含本机路径，不进入公开源码。公开案例另做内容和元数据审阅；另一台电脑、新账号或其他 Resolve 版本未实测就不记为通过。
